봇 로그에 PnL +$512가 찍혔다.

뭔가 이상했다. 핑퐁봇이 그 정도 수익을 냈다고 보기엔 너무 컸다. 코드를 봤다.

```python
real_pnl = actual_balance - initial_balance
```

`initial_balance`는 봇을 처음 시작했을 때 잔고다. `actual_balance`는 현재 잔고. 차이가 PnL이라고 계산하고 있었다.

문제는 중간에 **$500을 입금했다는 것**이다.

입금하면 잔고가 오른다. 봇은 그 차이를 수익으로 잡는다. 실제 트레이딩 수익이 +$12였는데, 입금 $500이 더해져서 +$512로 보였던 거다.

## 올바른 계산

거래소는 fills(체결 내역)를 제공한다. 각 체결마다 실현손익이 찍힌다.

```python
fills = client.get_fills(product_id)
total_pnl = sum(f["realized_pnl"] for f in fills)
```

잔고 기반이 아니라 체결 기반으로 합산하면 입금/출금과 완전히 분리된 순수 트레이딩 PnL이 나온다.

수정 후:

```python
real_pnl = ps.get("total_pnl", 0)  # fills 기반 누적
print(f"PnL ${real_pnl:+.2f}")
```

+$512 → +$12. 수익은 훨씬 작아졌지만 진짜 숫자다.

## 교훈

잔고 차이로 수익을 계산하면 안 된다. 입금, 수수료, 펀딩비, 포지션 평가손익이 전부 섞인다.

자동화 봇에서 수익을 측정할 때는 체결 기반 실현손익을 써야 한다.

로그가 이쁘게 찍히고, 숫자가 커 보여도, 계산 방식이 틀리면 의미 없다. 봇이 잘 돌아가고 있다는 착각에 빠지기 쉬운 지점이다.

```
수익이 크게 보인다 → 계산 방식부터 의심해라
```
