교사용 앱을 만들기 시작했습니다.

원래는 학급별 수업 진도를 기록하는 도구였습니다. 학년, 반, 단원, 차시를 입력하면 마지막 수업이 어디까지 갔는지 바로 보이는 구조였습니다.

그런데 만들다 보니 방향이 바뀌었습니다.

---

## 방향이 바뀐 이유

단원과 차시를 입력하는 게 귀찮습니다. 결국 메모만 쓰게 됩니다.

그리고 마침 경제 신문을 구독하기 시작했습니다. 읽으면서 정리할 공간이 필요했습니다.

그래서 jindo는 두 가지를 합친 앱이 됐습니다.

- 수업 진도 메모 (학년별, 반별)
- 경제 신문 메모 (키워드 + 내용)

---

## 기술 스택

- **Vite + React + TypeScript**: 빠른 빌드
- **localStorage**: 서버 없이 데이터 저장
- **NanumSquare 폰트**: 네이버 CDN으로 불러옴

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/moonspam/NanumSquare@2.0/NanumSquareWeb.css">
```

---

## 구조

탭이 3개입니다.

```
📚 수업    📰 경제    ✅ 할 일
```

하단에 고정된 네비게이션으로 탭을 전환합니다. React `useState`로 현재 탭을 관리합니다.

```tsx
type Tab = "class" | "econ" | "todo";
const [tab, setTab] = useState<Tab>("class");
```

---

## 경제 메모 화면

키워드와 내용을 따로 입력합니다.

키워드는 쉼표로 구분하면 해시태그로 표시됩니다.

```
키워드: 금리, 연준, 인플레이션
내용: 연준이 금리를 동결했다. 시장 반응은...
```

입력하면 이렇게 보입니다.

```
#금리  #연준  #인플레이션
연준이 금리를 동결했다. 시장 반응은...
```

날짜별로 묶어서 최신순으로 정렬됩니다.

---

## 수업 진도 화면

학년 탭(1학년/3학년)으로 나뉘고, 반을 선택하면 시트가 올라옵니다.

단원 차시 입력 칸은 없앴습니다. 메모만 씁니다.

기록이 쌓이면 해당 반의 최근 메모가 그리드에 미리보기로 보입니다.

---

## 데이터 저장 방식

서버가 없습니다. localStorage에 JSON으로 저장합니다.

```typescript
const STORAGE_KEY = "jindo_econ_memos";

export function useEconMemos() {
  const [memos, setMemos] = useState<EconMemo[]>(() => {
    const raw = localStorage.getItem(STORAGE_KEY);
    return raw ? JSON.parse(raw) : [];
  });
  // ...
}
```

폰에서 사용하면 폰에 저장됩니다. 맥에서 열면 맥에 저장됩니다. 기기 간 동기화는 없지만, 개인용이라 충분합니다.
